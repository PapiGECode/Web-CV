Visión general

Qué es y por qué existe

PabloSchefer.com es esta misma web, mantenida en el repositorio Web-CV. Presenta proyectos, experiencia y contacto mediante HTML estático, CSS y JavaScript. Las animaciones utilizan GSAP y las funciones de Vercel gestionan la actividad de GitHub y el contacto.

Problema

El reto

Presentar proyectos y trayectoria con una identidad visual propia, sin perder legibilidad, accesibilidad ni facilidad de navegación.

Solución

La respuesta

Una web estática con mejora progresiva: contenido accesible sin JavaScript, animaciones GSAP, imágenes adaptables y funciones pequeñas en Vercel. El contacto informa claramente de si prepara un borrador o dispone de envío directo.

Implementación

Puntos técnicos

HTML, CSS y JavaScript

Contenido estático y comportamiento progresivo, sin una aplicación React detrás de esta web.

GSAP y responsive

Animaciones y composiciones adaptadas a escritorio, tablet y móvil.

Funciones de Vercel

Actividad de GitHub con caché y formulario con estados de entrega explícitos.

Pruebas y publicación

Validación de recursos, pruebas de interfaz y despliegue desde GitHub.
